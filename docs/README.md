# Docs

- [`decisions/`](decisions/): the record of how this site was planned and why. It covers the
  audit of the old WordPress site, the content plan, the decisions made, and the build plan.
  Start with [`decisions/README.md`](decisions/README.md). It is a snapshot from November 2026
  and is not kept up to date as the site changes.
- [`archive/`](archive/): verbatim copies of the six pages on the old site. This is the source text
  for the page copy.
- [`bozeman-makerspace-design-system/`](bozeman-makerspace-design-system/): the design system for
  the brand (colors, type, components). Its `tokens.css` is a separate copy from
  `src/styles/tokens.css`, which is what the site actually uses.
