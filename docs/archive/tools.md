## Tool Wishlist

We decided to add an on-going tool wishlist here. If you have a tool you would like to donate to the space, drop us a
line at [makers@bozemanmakers.com](mailto:makers@bozemanmakers.com). New or used tools are accepted. Slightly broken
tools may also be accepted, however we do not want something that is absolutely broken and is headed to the trash bin.

  * More capable digital oscilloscope
  * Clamps (can you have too many?)
  * 3D Printer filament
  * Router bits
  * Unused (or lightly used) Arduino or Raspberry Pi boards
  * Cordless drills or impact wrenches
  * Common fasteners (wood and sheet metal screws, etc)
