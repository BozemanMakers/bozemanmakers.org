# Logos

The Bozeman Makerspace shield badge, as supplied, plus three single-colour versions recoloured from the same paths. Nothing was redrawn.

| File | Ink | Use on |
|---|---|---|
| shield-ink.svg | `ink` #211e1a | `paper`, `paper-2`. The default. |
| shield-paper.svg | `paper` (dark) #eee6d6 | `ink` panels and the dark theme |
| shield-enamel.svg | `enamel` outline, `ink` contents | Large, celebratory use on `paper` only (96px+). |
| shield-original.svg | black outline, #424141 contents | Reference: the file as supplied |

Minimum height is 96px. Clear space is one saw-blade width on every side.
