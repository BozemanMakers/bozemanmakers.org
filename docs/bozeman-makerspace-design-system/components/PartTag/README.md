# PartTag
A stamped inventory tag for categories, shop areas and status — mono uppercase with a little punched hole.

- Variants by shop area: `bzm-tag--wood` (brass-ink), `bzm-tag--electronics` (gauge), `bzm-tag--metal` (ink), `bzm-tag--stop` (stop red, for *Few seats left* or *Closed*).
- Colour is never the only cue: the words say the category.
- Keep to one or two words. Part-number style IDs (`BZM-014`) are welcome.

The consumer provides: the text and the variant class.
